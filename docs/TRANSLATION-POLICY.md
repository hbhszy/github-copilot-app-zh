# 翻译边界与维护规则

浏览器侧实现位于 `src/overlay/*.mjs`，机器结果规则位于 `src/machine-policy.mjs`。所有归属判定集中在 `classifier.resolve()`，不由语言模型猜测任意文本的用途。模块职责见 [架构](ARCHITECTURE.md)，工具命令见 [开发与诊断](../CONTRIBUTING.md)。

## 两个独立判断

先通过 DOM 区域、固定标记和可访问性关系判断文本用途。用户内容、代码、输入值、文件/项目/模型名称等不因命中词典而成为界面文案。无法识别的区域不做自动翻译。

在已确认区域，先使用人工词典；没有匹配项时使用按区域和原文区分的本地机器缓存，再调用离线 Edge 引擎。词典可以纠正译文，也可以将原文映射为自身来阻止机器翻译。异步结果返回时会再次检查区域、节点原文、页面实例和人工覆盖项；机器失败时，新增的人工覆盖仍然优先。

因此，“新文案无需逐条维护”与“未知区域默认保留”并不矛盾。前者依赖区域识别，后者避免将用户资料当作 UI。没有一种单词数、大小写或字典命中规则可以单独证明文本归属。

## 已识别区域

| 区域 | 自动翻译对象 | 保留对象 |
| --- | --- | --- |
| 设置导航 | 第一组导航中的固定按钮，包括新标签；`data-selected` / `aria-pressed` 的存在或真假不改变其用途 | 其他导航组内的项目名称 |
| 设置 section | general/sessions/themes/accessibility/experimental 固定标题、与标题并列的说明及其行内链接文字、符合条件的操作标签和输入提示 | 输入值、任意数据段落、账户/提供商资料、主题卡片、按下/选中控件的数据值 |
| 设置表单、账户与固定枚举 | label/help/action 与控件关系确认的说明、账户套餐/配额标签、已识别时长单位 | 提供商/模型/账户身份、套餐名、声音文件名、当前数据值；组合标签仅翻译固定外壳 |
| 快捷键窗口、命令面板与会话菜单 | 标题/键帽结构确认的快捷键分组和命令、命令面板固定操作、可信菜单归属下的固定控件 | 键位、最近会话、工作区/项目名、未知数据选项 |
| 已识别弹窗 | 模式、添加上下文、新建项目/会话、自动优化的固定说明与选项 | 文件/项目/模型选择器中的数据项；模型菜单仅特殊处理固定 Auto 标签 |
| 固定提示 | 通过 `aria-describedby` 关联到已确认固定或通用 UI 按钮的提示；已知无 role 提示的文字匹配回退 | 来自聊天区/数据项控件的提示、无可信关联的新提示 |
| 首页及自动化 | 已有固定标记的首页示例、自动化介绍和内置模板 | 普通正文、自定义工作流及技能卡片 |
| 我的工作列表 | `/mywork` 固定列表面板内的视图控件、所有仓库选项及已确认的居中空状态组件，视图菜单按控件归属识别 | 议题/拉取请求标题、仓库选中值、输入内容；空状态引用的筛选文本只做外壳翻译 |
| 工作区右侧面板 | 内置面板标签、添加标签菜单固定项、Browser 工具栏与空状态说明 | 相关会话中的议题/仓库身份、URL 输入值、嵌入网页内容、未知数据标签 |
| 反馈窗口 | 固定说明、标签、按钮与输入提示，支持 aria-label 或标题 ID 命名 | 用户已写入的反馈正文 |
| 自定义页七个 TAB | 搜索提示、目录标题/说明、分类、空状态、标准操作；精选卡片和可用目录行的介绍 | 项目名称、市场名称、星数、输入和开关值、已安装项目的任意本地说明及配置正文 |

已确认区域内的新单词、新说明都可以自动处理；路径、URL、疑似代码、超长文本等仍经过共享文本规则过滤。公共目录介绍采用下述字面量保护规则。说明中 `<a>` 的**显示文字**可以翻译，`href` 不修改。输入框只处理批准的提示属性，不处理 `value` 或编辑内容。

## 自定义页的字段级处理（v0.2.6）

页面地址、TAB 面板和目录结构共同确定范围：精选、MCP、插件、技能、扩展、画布、已安装。目录节使用标题引用与列表引用确认关联；插件可用列表另识别其虚拟列表标记。卡片和行分别处理名称、介绍、类型标签、操作文案，不能因为一个按钮包含介绍就翻译整个按钮。行的描述 ID 必须引用该行内部的说明；没有有效关联的数据默认保留。虚拟列表新增或复用的行仍按相同规则处理。

`catalog.ui` 负责固定目录界面，`catalog.categories` 负责分类术语，`catalog.descriptions` 可人工纠正公共介绍。MCP 分类中的 `Intelligence` 是“智能”，模型优化菜单中的同一个词仍为“能力优先”。词典翻译记录会跟踪词典范围，节点换用途时先撤销旧范围的译文，再按新范围处理。分类 TAB 的显示文字与用于测宽的隐藏副本同步翻译；不开放任意隐藏内容。

名称、星数、市场选中值和已安装项目的任意本地说明不送入引擎。`Install skill: 名称`、`Actions for 名称`、`Disable 名称` 等仅翻译固定前后缀，名称原样保留。已安装项目只处理固定 `Built-in` 标记等界面字段，不读取或翻译技能文件、配置、Canvas 内部内容。

公共目录介绍单独使用 `page:catalog-description-v1:#text` 缓存范围，长度上限为 2400 字符。在已确认的介绍中，行内反引号、路径、网址和文件名字面量先保护后翻译周围文字；返回后逐一核对字面量、数字和占位符，新增或损坏的字面量拒绝写回。真正的 `code` / `pre` 节点仍完全排除。其他界面保留原有 480 字符限制和文本过滤规则；已有 version-5 缓存不因新增目录范围而作废。新目录缓存记录包含 context，重新加载时使用同样的校验。

`tools/survey-customize.mjs` 与 `tools/verify-customize.mjs` 会切换七个 TAB，前者采集结构，后者检查译文、名称、输入与开关/选择状态；加 `--screenshots` 时尝试保存截图，截图超时单独记录，不当作视觉验证通过。仅在自定义页无对话框且搜索为空时运行，结束时恢复原 TAB；不安装插件、不点击启停开关、不编辑查询、不刷新或提交任务。原始结构和截图可能包含本机项目资料，仅保存在被忽略的 `.local`。

目录控件或标题晚于说明挂载时，会重新扫描该卡片/列表组件中的兄弟节点，而不是仅扫描新插入的按钮。扫描仍由变更触发，不增加周期性全页扫描。

## 账户、固定设置选项与聊天信息补充

账户页不依赖不存在的 `accounts-*` section ID：通过 `data-settings-header`、固定的账户连接标题/添加操作和相邻账户列表共同确认区域。头像一侧的账户名、账户标识与套餐名称按数据处理；套餐标题、升级说明、进度条旁的配额标签和帮助说明按字段翻译。`accountSettings` 词典将 `Plan` 译为“套餐”，不修改规划模式的同名词条。百分比、进度条值和帮助链接地址不改动。

新增账户、账户操作与已识别设置枚举的弹出菜单，通过 `aria-labelledby` / `aria-controls` 回溯所属控件。设置名称与当前值组合的无障碍标签只翻译固定外壳；明确的时长枚举可翻译单位。声音菜单的文件名称和当前声音名称即使命中字典也保持原样，只翻译“打开音频文件”等已确认操作，不把声音选择器的任意悬停内容当作固定说明。

聊天信息菜单与工作区会话信息对话框分开识别：聊天菜单只新增统计定义列表、可校验的复制操作属性及对应字段标签，不将整张菜单开放给机器翻译。会话名称和 ID 即使等于 `Save` 或 `Session name` 也属于数据。聊天输入器只处理真实 placeholder 属性或独立的可见 placeholder 节点；草稿中出现同一句提示也不得替换。`Fork chat from response` 是明确的消息操作例外，`translate="no"`、代码和编辑区域不能借此绕过保护。

## 诊断边界

优先只读盘点，交互检查需显式 `--interact` 并满足 [工具前置条件](../CONTRIBUTING.md)。不输入、保存、授权、安装或发送消息；被遮挡、不可达或未实际打开的目标记为跳过。消息操作栏可能需先悬停显现，不能直接将不可见按钮判为漏翻。

默认报告只保存分类元数据并遮蔽会话路由，显式 `--include-text` 才保存候选文案。英文候选可能是数据、品牌或尚待翻译的 UI，不据此计算覆盖率。报告仅留在 `.local/`，对外分享前必须人工检查。

## 动态 UI 与队列

候选队列最多保留 128 项；首次扫描溢出的候选不被标记为已处理。队列降到 64 项或以下时补扫一次，避免对每个回复或空闲时间反复扫描。状态中的 `overflow`、`refills`、`expired` 都只是计数/标记，不记录被保护的正文。

两分钟未返回的请求失效；在总尝试次数不足两次时生成新 ID 重试，旧回复不能再落地。失败结果使用一分钟退避。失败两次后保留原文，不无限调用引擎。

React 复用节点、将节点移入聊天区、添加保护标记或改变弹窗关系时，会重新检查受影响记录。仅在显示值仍等于本工具写入的译文时恢复原文，宿主的新内容不覆盖。宿主在同一节点重新写入相同英文后，可以再次走缓存。保护区的流式字符更新和不涉及范围识别的动画 class 变化不触发扫描。

## 菜单归属与可解释诊断（v0.2.5）

弹窗所有者可以是普通按钮，也可以是 `role=menuitem` 的子菜单触发器。通过多 ID 的 `aria-labelledby` / `aria-controls` 追溯到可信入口，支持用户操作菜单、主题配色子菜单及固定分组/排序控件。缺失、循环或源于受保护区域的归属关系不会进入自动翻译；已确认控件族内的新文案无需逐条加词典。

“跟随系统/浅色/深色”是固定配色选项，不是用户安装的主题名称；主题卡片、模型和项目数据仍保留。账户菜单的身份卡片不走词典或机器翻译，只对可校验的 `Chat messages used: 数值%` 状态片段做模板替换，不改变账户名和百分比。

账户入口的 `<name>, open user menu` 只翻译无障碍标签中的固定后缀。入口内的可见账户名以及其他身份属性按数据处理，即使命中词典或看起来像 `Session: <name>` 模板也不翻译；整条带名称的标签不提交机器翻译。菜单归属仍使用记录的原始标签判断。

提示通过 `aria-describedby` 关联到通用 UI 按钮时，沿用该按钮的既有归属与数据排除规则，不要求按钮文案先命中词典。已挂载浮层的 `data-popup-open`、提示触发器标记和 `aria-haspopup` 变化会重新检查被移到独立 DOM 容器的浮层；关系丢失后撤回依赖该关系且仍由汉化层持有的机器译文，并拒绝迟到回复。该重扫由 DOM 变化触发，不增加定时轮询。

“我的工作”使用独立的 `mywork` 词典范围，不把 `Nothing here` 等词条加入通用按钮或任意页面正文。列表滚动区域默认视为数据，仅在固定面板内确认居中空状态结构和标题后开放其标题、说明；同名议题按钮或其他页面正文不翻译。`No items match "<filter>".` 只翻译外壳，保留引用的筛选文本，包括与词典冲突的单词和 `$&` 等字面量。空状态标题晚于说明挂载时重扫该组件，标记丢失后恢复并拒绝迟到结果。

维护者可调用 `window.__copilotChinese.explain(element)` 查看 `dictionary`、`machine`、`protected`、`unclassified`、`text-filter` 等分类，不返回原文或译文。它是按需诊断，不会后台收集整个页面的用户内容。新增机器候选只发送无正文的就绪信号，正文仍由已有的受限候选队列校验后读取。

## 遗漏发现

`tools/discover-untranslated.mjs` 只读盘点当前可见页中 `unclassified` / `text-filter` 候选，默认不保存原文、ID、类名或输入值，也不触发翻译。结构路径只对当前页面有效；不能把未挂载页面或保护区域视为已审计。

候选必须按实际文本节点调用 `explain()`，不能用父容器合并文字代替：同一按钮内的模型名与推理强度可能分别属于数据和 UI，否则会把已翻译标签误报为漏翻。

## 新增适配的顺序

新增术语或修正译文，修改 `locales/zh-CN.json`。新增结构，先提供区分 UI 与数据的稳定标记或可访问性关系，再扩展范围函数。不要把所有按钮、段落、提示或整张第三方卡片无差别交给引擎。

每个范围扩展至少测试：没有词条的新文案能入队；同名用户/模型/文件数据不变；控件关闭、改用途或节点迁移后的迟到回复无效；停止汉化能恢复原文。测试使用 jsdom 与模拟引擎，不需要发送真实聊天消息。

自动测试验证边界和状态机，不能证明每条机器译文语义准确，也不能替代新 Copilot 版本的实际界面验证。不要把词条数或测试通过数量当作整体汉化覆盖率。

设置导航回归用例应保留真实结构中的 `ul > div > button`、选中与未选中的 `data-selected` 属性，以及同名项目项。不能只用没有状态属性的简化按钮替代。真实页面可用 `tools/verify-settings-navigation.mjs` 只读验证；更新前运行 `--baseline`，更新后再运行默认模式对比，不点击导航或改动输入。
